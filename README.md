# 医防协同随访枢纽

本服务用于多机构慢病线索、授权和转介责任。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：机构、患者别名、风险线索、授权、转介、责任人、访问记录、拆分审批。

迟到事件不能倒退已确认状态；授权撤回立即限制新访问；错误合并的拆分需双人批准；机构只获得完成转介所需信息。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/care_referral.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
